# Tommy Robins

Real estate acquisitions analyst and MSRE student at NYU Schack (Real Estate Finance and Investment, May 2027). I work on value-add industrial acquisitions in Florida at Anchor Capital Group, and I build data tools that make the sourcing and underwriting work faster.

This page collects the tools, models and research I've built. Each project links to a write-up covering the problem, what I built, and what it found.

## Data tools and automation

| Project | What it does | Built with |
|---|---|---|
| [Muskoka Development Pipeline](projects/muskoka-development-pipeline) | One map of every planning application and building permit across Muskoka, Ontario, a market where the data is split across six townships and a district GIS | HTML/JS, ArcGIS REST, SheetJS |
| [Industrial distress signal monitor](projects/industrial-distress-monitor) | Scores private industrial owners on how likely they are to sell, using public records, so off-market outreach starts with the best targets | Python, county public records |
| [Off-market sourcing pipeline](projects/off-market-sourcing-pipeline) | Turns raw Reonomy exports of 1,000+ properties into a filtered, CRM-ready call list of mom-and-pop owners | Python (pandas), Airtable |
| [Multifamily asset management dashboard](projects/multifamily-asset-dashboard) | Interactive occupancy, rent roll and lease expiration dashboard for a 5-property, 240-unit portfolio | HTML/JS, pandas |
